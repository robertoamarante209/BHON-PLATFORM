# Visão do Produto

A BHON é uma plataforma operacional para clínicas odontológicas.

Seu objetivo é ajudar clínicas a identificar, organizar e recuperar oportunidades perdidas de forma simples, inteligente e escalável.

A BHON não é apenas um CRM.

A BHON é a camada operacional da clínica.

---

# Problema

Milhares de clínicas perdem receita todos os dias porque:

- pacientes não retornam;
- orçamentos não recebem acompanhamento;
- tratamentos são abandonados;
- faltas não recebem ação;
- informações ficam espalhadas;
- equipes trabalham de forma reativa.

O resultado é perda de crescimento e baixa previsibilidade.
